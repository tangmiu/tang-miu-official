# Tang Miu — Official Artist Website

Static GitHub Pages website for Tang Miu.

## Deploy
Upload the contents of this folder to the root of the `tang-miu-official` repository and keep GitHub Pages set to `main` / `/ (root)`.

## Included
- Responsive single-page artist site
- Artist logo and supplied photography
- Music, live, covers, about and contact sections
- JSON-LD Person structured data with canonical social profiles
- Open Graph / Twitter metadata
- `robots.txt` and `sitemap.xml`
