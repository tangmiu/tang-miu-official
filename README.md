# Tang Miu Official Website

A simple static artist website designed for GitHub Pages.

## Before publishing
Replace the placeholder links marked `href="#"` with Tang Miu's real Spotify, Apple Music, YouTube, Instagram and TikTok URLs.

The JSON-LD `sameAs` values in `index.html` should also be replaced with the real profile URLs.

## Publish for free
1. Create a GitHub account if you do not have one.
2. Create a PUBLIC repository named `YOURUSERNAME.github.io`.
3. Upload `index.html` and `style.css`.
4. Open Settings → Pages.
5. Choose “Deploy from a branch”, select `main`, folder `/ (root)`, and Save.
6. Open `https://YOURUSERNAME.github.io`.

You can connect a custom domain later.
