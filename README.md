# Tang Miu — Official Artist Website

Official artist website for Tang Miu, deployed on Vercel:

https://tang-miu-official.vercel.app/

## Deploy

The site is a static HTML/CSS/JavaScript website. The production site is hosted on Vercel. When the GitHub repository is connected to Vercel, pushes to the production branch (usually `main`) trigger a deployment. If automatic deployments are not connected, deploy the latest repository contents from the Vercel dashboard.

The previous GitHub Pages URL is retained as a legacy copy for now. Do not disable it until the new Vercel site and Google Search Console migration have been checked.

## Included

- Responsive artist website and official artist profile
- Music, live performances, covers, creative works, biography and contact sections
- Artist logo and photography
- JSON-LD structured data and canonical URLs for the Vercel site
- Open Graph / Twitter metadata
- `robots.txt` and `sitemap.xml`
